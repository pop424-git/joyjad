## หน้าแรก

### คนทั่วไป (จอดูสด)

จอสีเข้มเต็มใบ (โทนเดียวกับตัวหนังสือ) — โลโก้จอยจัดพื้นโปร่งใสลอยกลางจอ การ์ดชมพูอ่อนบอกสนามกับเวลา

มีแค่นี้ ไม่มีกติกา ไม่มีตัวเลือกสนาม เพราะคนดูกดอะไรไม่ได้อยู่แล้ว · พอแอดมินเริ่มก๊วน หน้านี้เปลี่ยนเป็นจอดูสดให้เอง

ถ้าแอดมินตั้งนัดไว้ การ์ดนัดจะมาแทนการ์ดสนาม/เวลา

### แอดมิน

การ์ดพื้นเข้มใบเดียวกับจอดูสด — โลโก้ + ปุ่ม **ตั้งนัดวันนี้** สีขาว · ใต้การ์ดคือ **โหมดการเล่น** กับตัวเลือกสนาม แล้วปุ่ม **ถัดไป**

## โหมดการเล่น

| โหมด | จบเกมแล้ว | เล่นติดได้ |
|---|---|---|
| **2 ออก 2** (ค่าเริ่มต้น) | ออก 2 เข้า 2 — ชนะอยู่ต่อ | 2 เกม |
| **4 ออก 4** | เปลี่ยนยกชุด | 1 เกม |

เลือกที่หน้าแรกก่อนเริ่ม หรือกดป้ายโหมดบนหัวคิว **สลับกลางก๊วนได้** — มีผลกับเกมถัดไปทันที ไม่รีเซ็ตจำนวนเกมที่แต่ละคนเล่นไปแล้ว

คนรอคิวไม่พอก็ไม่ติด — โหมด 4 ออก 4 แต่มีคนรอ 2 ก็สลับ 2 คนตามที่มี · โหมดที่เลือกไว้จำข้ามก๊วน และซิงก์ไปจอดูสดด้วย (คนดูเห็นป้ายแต่กดสลับไม่ได้)

## ตั้งนัดล่วงหน้า

กดปุ่ม **ตั้งนัดวันนี้** (หรือ **แก้ไขนัด** ที่มุมขวาบนเมื่อมีนัดแล้ว)

- **สนามไม่ต้องกรอก** — ก๊วนนี้เล่นที่ Grand Valley ที่เดียว (ค่าคงที่ `CLUB_VENUE`)
- **เวลาตั้งต้น 19:00-21:00** แสดงเป็น 24 ชม. เสมอ · วันอาทิตย์เวลาไม่เหมือนศุกร์ กด **เปลี่ยนเวลา** แล้วเลือกจาก dropdown (06:00-23:30 ทีละครึ่งชั่วโมง)
- เลือกวันที่ · เลือกคอร์ท (ได้ถึง 4 แสดงครบในแถวเดียว) · แตะเลือกคนที่มาจากรายชื่อส่วนกลาง
- บันทึกแล้ว **เติมให้หน้าตั้งค่าอัตโนมัติ** — จำนวนสนามกับเลขคอร์ทตามที่ประกาศ และเลือกคนในนัดไว้ให้
- การ์ดหายเองหลังเลยเวลาเลิก 3 ชั่วโมง หรือกด **ล้างนัด**
- เก็บคนละ key กับสถานะก๊วน — จบก๊วนแล้วการ์ดนัดยังอยู่

## เริ่มใช้งาน (2 ขั้น + เข้าสนามเมื่อคนมา)

1. **เลือกโหมดการเล่นกับจำนวนสนาม** 1-4 แล้วแตะเลือกเลขสนามจริง (มีให้เลือก 6 สนาม เลือกไม่ติดกันก็ได้)
2. **เลือกผู้เล่น** — แตะชื่อจากรายชื่อที่จำไว้ หรือพิมพ์เพิ่ม · ตัวเลขบนชื่อ = ลำดับคิว → **ถัดไป · เข้าสนาม**
   - แต่ละชื่อมี badge ระดับฝีมือกำกับ (Rookie / BG1 / BG2 / NB / N / S) แตะ badge เพื่อแก้ระดับได้ที่หน้าจัดการรายชื่อ
3. เข้าหน้าเล่นแล้วเจอสนามว่างทุกช่อง — ไม่ต้องจัดครบทุกสนามก่อนเริ่ม ใครมาก่อนจิ้มสนามนั้นได้เลย (ดูหัวข้อ **ระหว่างเล่น**)

### ระหว่างเล่น

- สนามว่าง = ปุ่ม **จัดคนลง** เต็มช่อง จิ้มแล้วเลือก 4 คนจากคิว **ยืนยัน** ปุ๊บเริ่มจับเวลาสนามนั้นทันที (สนามอื่นจัดทีหลังได้ ไม่ต้องรอพร้อมกัน)
- จำนวนเกมนับตอน**กดเริ่ม** ไม่ใช่ตอนจบเกม — ปิดแอปหรือจบก๊วนกลางเกมก็ไม่เสียเกมสุดท้ายไป
- จบเกมกด **จบเกม** เลือกคนออก/เข้าใหม่ตามคิว · เปลี่ยนคนกลางเกม (โดนเรียก/มาสาย) กดที่ตัวผู้เล่นในสนาม
- ป้ายโหมด (2 ออก 2 / 4 ออก 4) บนหัวคิวกด**สลับกลางก๊วนได้** มีผลเกมถัดไปทันที ไม่รีเซ็ตเกมที่เล่นไปแล้ว

## จบก๊วน + คิดเงิน

สรุปกับคิดเงินรวมเป็นหน้าเดียว กดจากปุ่ม **สิ้นสุดก๊วน** บนหัวจอ:

- ช่องกรอกยอดรวมช่องเดียว — ค่าเริ่มต้น = จำนวนสนาม × 400 บาท แก้ทับเป็นยอดจริงได้ (ผู้จัดบวกค่าสนาม+ค่าลูกมาเองแล้ว)
- **2 ออก 2** หารเท่ากันทุกคนเสมอ
- **4 ออก 4** มีสวิตช์เลือก **หารตามเกม** (ค่าเริ่มต้น — เล่นเยอะจ่ายเยอะ) หรือ **หารเท่ากัน** ผู้จัดสลับได้ทุกเมื่อ
- หารตามเกม: จัดกลุ่มคนตามจำนวนเกมที่ลง แสดงยอดต่อกลุ่ม เศษปัดขึ้นให้ลงตัวที่ 1 บาท (ส่วนเกินตกเป็นของผู้จัด)
- หารเท่ากัน: ยอดเดียวกันหมด โชว์ตัวเลขใหญ่ก้อนเดียว ตามด้วยสรุปว่าใครเล่นไปกี่เกม (ดูเฉยๆ ไม่มีตัวเลขเงินกำกับ)

### QR จ่ายเงิน

- **รูป QR ฝังอยู่ในโค้ดถาวรแล้ว** (ตัวแปร `QR_PAY` ใน `index.html`) — ไม่มีปุ่มอัป ไม่ต้องตั้งค่าอะไรทั้งนั้น
  - รูปเป็น data URL (JPEG ด้านยาว ~700px) + ชื่อบัญชี อยู่ในไฟล์เดียวกับตัวเว็บ
  - **ถ้า repo นี้เป็น public** — รูป QR กับชื่อบัญชีจะเห็นได้จาก GitHub ด้วย (พร้อมเพย์ปกติแปะให้คนสแกนอยู่แล้ว ถ้าไม่โอเคค่อยย้าย repo เป็น private)
  - จะเปลี่ยนบัญชี: แก้ `QR_PAY` ที่เดียวแล้ว push — ทุกเครื่องเห็นรูปใหม่ตอนรีเฟรช
- ปุ่ม **💸 จ่ายเงิน** อยู่มุมขวาบนของหน้าสรุป (ทั้งแอดมินและคนดูสดกดได้) → เต็มจอ: **ยอดต่อคนตัวใหญ่** (ถ้าหารเท่ากันทุกคน) + QR + ชื่อบัญชี
- **หารตามเกม** (4 ออก 4) แต่ละคนจ่ายไม่เท่ากัน เลยไม่มีเลขเดียวให้โชว์ — หน้าต่าง QR ขึ้นข้อความชี้กลับไปที่การ์ดกลุ่มแทน
- QR พร้อมเพย์แบบนี้ไม่ได้ล็อกยอด คนสแกนกรอกเงินเอง
- รูปมากับหน้าเว็บเลย **เน็ตหลุดกลางคอร์ทก็ยังเปิดสแกนได้**

## รายชื่อส่วนกลาง (ทุกเครื่องเห็นตรงกัน)

รายชื่อผู้เล่นเก็บบนเซิร์ฟเวอร์ ผ่าน `/api/roster` (Vercel KV / Upstash Redis) — รวมระดับฝีมือของแต่ละคนด้วย

- ใครเปิดลิงก์ก็ **เพิ่ม/ลบชื่อได้** ไม่มีล็อกอิน
- ชื่ออยู่ถาวรจนกว่าจะกดปุ่ม **ล้างรายชื่อ** (ถามยืนยัน 2 ครั้ง เพราะกระทบทุกเครื่อง)
- แตะ badge ระดับข้างชื่อเพื่อแก้ระดับได้จากหน้าจัดการรายชื่อ

## ตั้งค่า Vercel KV / Upstash (ทำครั้งเดียว)

ใช้ตัวเดียวกันทั้งรายชื่อส่วนกลาง (`/api/roster`) และโหมดดูสด (`/api/state`) — ตั้งค่าที่เดียวจบ

1. เปิดโปรเจกต์ใน Vercel → แท็บ **Storage** → เพิ่ม **Upstash Redis** (มี free tier)
2. Vercel จะใส่ environment variables ให้เอง — ตัวที่แอปใช้คือ
   `KV_REST_API_URL` + `KV_REST_API_TOKEN` (หรือ `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN`)
3. **Redeploy** หนึ่งครั้งให้ตัวแปรมีผล

ยังไม่ได้ตั้งค่า → `/api/roster` ตอบ 503 แอปจะใช้รายชื่อในเครื่องแทน ใช้งานได้ปกติแค่ไม่ซิงก์
`/api/state` ก็ตอบ 503 เหมือนกัน → จอดูสด (ด้านล่าง) จะขึ้น "หลุดการเชื่อมต่อ" ตลอด แต่เครื่องแอดมินยังกดจัดคิวได้ปกติ

ตัวนับ "คุมอยู่กี่คน" นับเฉพาะเครื่องที่เข้าโหมดแอดมิน (poll ทุก 60 วิ) — จอดูสดไม่ต้อง check-in เลย ประหยัด Redis command ไปมาก

## โหมดแอดมิน กับ จอดูสด

**เปิดลิงก์เฉยๆ = จอดูสด** อ่านอย่างเดียว — เห็นสนาม คิว การ์ดนัด และป้ายเรียกลงสนาม แต่กดอะไรไม่ได้

**เข้าโหมดแอดมิน:** แตะที่โลโก้ **จอยจัด** 5 ครั้งใน 2.5 วินาที (แตะที่หน้าแรก หรือหัวจอตอนเล่นก็ได้) → เข้าโหมดแอดมิน · แตะ 5 ครั้งอีกทีเพื่อออก
เครื่องนั้นจำโหมดไว้ใน localStorage — ตั้งครั้งเดียวที่ iPad ที่ใช้จัดคิว ที่เหลือเปิดลิงก์ดูอย่างเดียว

- แอดมินกดอะไร **ทุกเครื่องเห็นตาม** ผ่าน `/api/state` — จอดูสดดึงทุก 3 วินาที (10 วินาทีตอนยังไม่เริ่มก๊วน) แอดมินเช็คอินทุก 3 วินาที
- ไฟบนหัวจอ: 🟢 **บันทึก HH:MM** (แอดมิน) · 🟢 **ดูสด HH:MM** (คนดู) · 🔴 = ต่อไม่ได้ หรือเบราว์เซอร์ปิดการเก็บข้อมูล (มักเป็น Safari Private Browsing)
- มีแอดมินหลายเครื่องได้ — เครื่องไหนแก้อะไร อีกเครื่องรับการเปลี่ยนแปลงตามให้เอง ไม่ทับกัน (ดูว่าแก้จากเครื่องอื่นด้วย toast แจ้ง)
- ก๊วนบนเซิร์ฟเวอร์หมดอายุเองใน 5 ชั่วโมง (เผื่อลืมกดสิ้นสุด)

### เปิดใหม่แล้วก๊วนหายไหม

สถานะก๊วนเก็บใน localStorage ของเครื่องแอดมินด้วย

- เปิดแอปครั้งถัดไป → ขึ้นหน้าเลือกสนามใหม่เสมอ
- **ยกเว้น** มีก๊วนค้างไม่เกิน 5 ชั่วโมง → กู้กลับให้อัตโนมัติ (เผื่อรีเฟรช/เครื่องดับกลางก๊วน)
- ถ้าเครื่องแอดมินหาย แต่มีอีกเครื่องเป็นแอดมินอยู่ ก๊วนบนเซิร์ฟเวอร์ยังอยู่ ดึงกลับมาได้

### หรือแบบลาก-วาง (ไม่ต้องใช้ Git)

1. เปิด https://vercel.com/new
2. เลื่อนลงหา **"or drag and drop"**
3. ลาก **โฟลเดอร์ `badminton-app`** ทั้งโฟลเดอร์เข้าไปวาง (อย่าลากแค่ไฟล์ `index.html` — โฟลเดอร์ `api/` ต้องไปด้วย)
4. กด **Deploy** รอประมาณ 20-30 วินาที
5. ตั้งค่า Storage ตามหัวข้อด้านบน แล้ว redeploy

## ทดสอบบนเครื่องตัวเอง

```bash
node .claude/serve.js
```

เปิด http://localhost:5173 (ต้องผ่าน server ไม่ใช่ดับเบิลคลิกไฟล์ ไม่งั้น localStorage ไม่ทำงาน)
dev server จำลอง `/api/roster` กับ `/api/state` (รวมนัดครั้งถัดไป) ไว้ในหน่วยความจำให้ด้วย — ทดสอบซิงก์ได้โดยไม่ต้องต่อ Upstash

ปุ่มลับสำหรับทดสอบ: `/api/_mock?clear=1` ล้างของจำลองทั้งหมด · `?seed=ชื่อ,ชื่อ` ใส่รายชื่อ · `?down=1` จำลองเน็ตหลุด · `?expireplan=1` ดันนัดให้หมดอายุทันที

## ไฟล์ในโฟลเดอร์

- `index.html` — ตัวแอปทั้งหมด (HTML + CSS + JS ไฟล์เดียว ไม่มี dependency) รวมโลโก้และ QR ที่ฝังเป็น data URL
- `api/roster.js` — API รายชื่อส่วนกลาง + ระดับฝีมือ (key `badminton:roster` / `badminton:levels`)
- `api/state.js` — สถานะก๊วนสด + นัดครั้งถัดไป + จำนวนแอดมินที่คุมอยู่ (key `badminton:state` / `badminton:plan` / `badminton:admins`)
- `vercel.json` — ตั้งค่า cache
- `.claude/serve.js`, `.claude/launch.json` — dev server สำหรับทดสอบ ไม่เกี่ยวกับตัวแอปตอน deploy

| จองได้สูงสุดกี่สนาม | `MAX_COURTS` (4, จองพร้อมกันได้สูงสุด) — คู่กับ `PLAN_MAX_COURTS` ใน `api/state.js` |

| โหมดการเล่น | `ROTATE_MODES` (ตัวเลือก) · `rotateOut` (ค่าปัจจุบัน) · `consecCap()` (เล่นติดได้กี่เกม) |
| จำนวนครั้งที่แตะเข้าโหมดแอดมิน | `TAPS_FOR_ADMIN` / `TAP_WINDOW_MS` |
| โลโก้ | `LOGO` (data URL) |
