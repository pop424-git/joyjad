# จอยจัด 🏸

เว็บแอปหน้าเดียวสำหรับจัดคิวก๊วนแบดมินตัน 1-6 สนาม เล่นคู่ ระบบเข้า 2 ออก 2
ธีมชมพู-ขาว · ออกแบบให้มือถือเป็นหลัก · รายชื่อผู้เล่นเก็บไว้ส่วนกลาง ทุกเครื่องเห็นตรงกัน

**ใช้งานจริง:** https://joyjad-badminton.vercel.app

หน้าแรกแสดงข้อมูลก๊วน (สนาม Grand Valley · ศุกร์ 19:00-21:00 · อาทิตย์ 18:00-20:00) และกติกาก๊วน
แก้ข้อความพวกนี้ได้ที่ `<section id="scSetup">` ใน [index.html](index.html)

## เริ่มใช้งาน (3 ขั้น)

1. **เลือกจำนวนสนาม** — 1-6 สนาม (1 สนามเล่นได้ 4-8 คน)
2. **เลือกผู้เล่น** — แตะชื่อจากรายชื่อที่จำไว้ หรือพิมพ์เพิ่มคนใหม่ · ตัวเลขบนชื่อ = ลำดับที่เลือก (ใช้เป็นลำดับคิว)
3. **เลือกคนลงสนาม** — แตะชื่อจากรายการล่างเพื่อใส่ลงสนามที่กำลังไฮไลต์ ครบ 4 คนแล้วเลื่อนไปสนามถัดไปเอง · แตะชื่อในสนามเพื่อเอาออก · หรือกด **จัดให้อัตโนมัติ** → **เริ่มจัดก๊วน**

## กติกาหมุนเวียน

- **เกมแรกของสนาม** — กด **จบเกม** → เลือก 2 คนที่จะออก
- **เกมถัดๆ ไป** — คนที่เล่นครบ 2 เกมติดถูกเลือกออกให้อัตโนมัติ กดยืนยันได้เลย (แก้ก่อนได้)
- คนที่ออกไปต่อท้ายคิวโดยลำดับติดกัน แต่ไม่ผูกว่าต้องลงพร้อมกันอีก
- หน้ายืนยันโชว์ **ใครออก / ใครลงแทน** เสมอ แตะเปลี่ยนได้ก่อนกดยืนยัน
- ตำแหน่งยืนในสนามไม่ล็อก ผู้เล่นตกลงกันเอง
- ถ้าไม่มีคนรอคิวเลย กดจบเกมจะนับเกมให้ทุกคนแล้วเล่นต่อได้เลย

## คิวรอ

- เรียงลำดับ 1, 2, 3... — **กรอบชมพู = 2 คนถัดไปที่จะได้ลง**
- ปุ่ม ▲▼ เลื่อนคิวขึ้น/ลง (เช่นอยากดันคิวที่ 3 ขึ้นมาก่อน)
- "N เกม" = จำนวนเกมที่คนนั้นเล่นไปแล้ว

## ระหว่างเกม

- **แตะชื่อคนในสนาม** = เปลี่ยนตัวกลางคัน คนที่ออกจะไปรับคิวของคนที่ลง (ไม่นับเป็นจบเกม)
- **ช่องว่าง** = แตะเพื่อดึงคนจากคิวลง
- **รายชื่อ** = เพิ่มคนมาสาย / ปิดสวิตช์คนที่กลับบ้าน (ออกจากสนามและคิวทันที แต่ยังนับในการหารเงิน)

## จบก๊วน

กด **สิ้นสุดก๊วน** บนหัวจอ:

1. **สรุปเกม** — ใครเล่นไปกี่เกม เรียงมากไปน้อย (กลับไปเล่นต่อได้)
2. **คิดเงิน** — กรอกค่าสนามรวม + จำนวนลูกแบดที่ใช้ + ราคาต่อหลอด (12 ลูก)
   - ค่าลูก = ลูกที่ใช้ ÷ 12 × ราคาหลอด
   - **หารเท่ากันทุกคนที่มาวันนี้ ปัดขึ้นเป็นบาท** พร้อมบอกยอดที่เก็บได้และเศษที่เกิน
   - ค่าสนามกับราคาหลอดถูกจำไว้ให้ครั้งหน้า
3. กด **เริ่มจัดก๊วนใหม่** เพื่อเริ่มรอบใหม่

## รายชื่อส่วนกลาง (ทุกเครื่องเห็นตรงกัน)

รายชื่อผู้เล่นเก็บบนเซิร์ฟเวอร์ ผ่าน `/api/roster` (Vercel KV / Upstash Redis)

- ใครเปิดลิงก์ก็ **เพิ่ม/ลบชื่อได้** ไม่มีล็อกอิน
- ชื่ออยู่ถาวรจนกว่าจะกดปุ่ม **ล้างรายชื่อ** (ถามยืนยัน 2 ครั้ง เพราะกระทบทุกเครื่อง)
- แถบสถานะบนหน้าเลือกผู้เล่น:
  - 🟢 **รายชื่อส่วนกลาง N คน** = ซิงก์ปกติ
  - 🔴 **ต่อส่วนกลางไม่ได้** = ใช้รายชื่อที่แคชไว้ในเครื่องต่อได้ ชื่อที่เพิ่มตอนเน็ตหลุดจะถูกส่งขึ้นให้เองเมื่อกลับมาต่อได้
- กด **รีเฟรช** เพื่อดึงชื่อล่าสุดที่เครื่องอื่นเพิ่งเพิ่ม

### ตั้งค่า Vercel KV / Upstash (ทำครั้งเดียว)

ใช้ตัวเดียวกันทั้งรายชื่อส่วนกลาง (`/api/roster`) และโหมดดูสด (`/api/state`) — ตั้งค่าที่เดียวจบ

1. เปิดโปรเจกต์ใน Vercel → แท็บ **Storage** → เพิ่ม **Upstash Redis** (มี free tier)
2. Vercel จะใส่ environment variables ให้เอง — ตัวที่แอปใช้คือ
   `KV_REST_API_URL` + `KV_REST_API_TOKEN` (หรือ `UPSTASH_REDIS_REST_URL` + `UPSTASH_REDIS_REST_TOKEN`)
3. **Redeploy** หนึ่งครั้งให้ตัวแปรมีผล

ยังไม่ได้ตั้งค่า → `/api/roster` ตอบ 503 แอปจะใช้รายชื่อในเครื่องแทน ใช้งานได้ปกติแค่ไม่ซิงก์
`/api/state` ก็ตอบ 503 เหมือนกัน → โหมดดูสด (ด้านล่าง) จะขึ้น "หลุดการเชื่อมต่อ" ตลอด แต่เครื่องแอดมินยังกดจัดคิวได้ปกติ

## โหมดดูสด (แชร์คิว/สนามให้เครื่องอื่นดู)

เปิดลิงก์แอปครั้งแรก = โหมด **ดูสด** (read-only) เสมอ ไม่ต้องตั้งค่าอะไร

- เห็นคิว/สนามอัปเดตสดตามเครื่องแอดมิน โดยดึงข้อมูลใหม่ทุก 5 วินาที (`/api/state`)
- **แตะโลโก้ "จอยจัด" ติดกัน 5 ครั้ง** เพื่อสลับเข้า/ออกโหมด **แอดมิน** — จำไว้เฉพาะเครื่องนั้น (localStorage)
- เฉพาะเครื่องแอดมินเท่านั้นที่กดจัดคิว/จบเกมได้ ทุกครั้งที่เซฟจะส่งสถานะขึ้นให้เครื่องดูสดเห็นตาม
- แถบสถานะบนหัวจอ: 🟢 "ดูสด HH:MM" = เชื่อมต่อปกติ · 🔴 "หลุดการเชื่อมต่อ" = ต่อ server ไม่ได้
- ตัวนับ 👀 "N คนออนไลน์" — ฝั่งแอดมินจะนับไม่รวมตัวเอง ("N คนกำลังดู")
- **แอดมินได้หลายเครื่องพร้อมกัน** — ถ้าอีกเครื่องจบก๊วน/เริ่มก๊วนใหม่ไปแล้ว เครื่องที่ค้างจะดึงสถานะล่าสุดมาแทนอัตโนมัติ กันก๊วนเก่า push ทับก๊วนใหม่
- ก๊วนที่แชร์ไว้จะถูกล้างทิ้งเองถ้าไม่มีการเซฟใหม่นานเกิน 5 ชั่วโมง (กันลืมปิดก๊วนแล้วค้างให้คนอื่นเห็นของเก่า)
- ต้องตั้งค่า Vercel KV / Upstash ตามหัวข้อด้านบนก่อน ไม่งั้นโหมดดูสดจะขึ้น "หลุดการเชื่อมต่อ" ตลอด

## สถานะก๊วน (คิว/สนาม) — เก็บในเครื่องแอดมิน

นอกจากส่งขึ้น server ให้โหมดดูสด **เครื่องแอดมินยังเก็บสำรองไว้ใน localStorage ของตัวเองด้วย**
ให้ iPad เครื่องเดียวเป็นตัวหลัก คนที่ถือ iPad เป็นคนกด

- เปิดแอปครั้งถัดไป (ในโหมดแอดมิน) → ขึ้นหน้าเลือกสนามใหม่เสมอ
- **ยกเว้น** มีก๊วนค้างไม่เกิน 12 ชั่วโมง → กู้กลับให้อัตโนมัติ (เผื่อรีเฟรช/เครื่องดับกลางก๊วน)
- ไฟสถานะบนหัวจอ: 🟢 บันทึก HH:MM = ปกติ · 🔴 ไม่ได้บันทึก = เบราว์เซอร์ปิดการเก็บข้อมูล (มักเป็น Safari Private Browsing)

## อัปขึ้น Vercel (ลาก-วาง ไม่ต้องใช้ Git)

1. เปิด https://vercel.com/new
2. เลื่อนลงหา **"or drag and drop"**
3. ลาก **โฟลเดอร์ `badminton-app`** ทั้งโฟลเดอร์เข้าไปวาง (อย่าลากแค่ไฟล์ `index.html` — โฟลเดอร์ `api/` ต้องไปด้วย)
4. กด **Deploy** รอประมาณ 20-30 วินาที
5. ตั้งค่า Storage ตามหัวข้อด้านบน แล้ว redeploy

## ทดสอบบนเครื่องตัวเอง

```bash
node .claude/serve.js
```

เปิด http://localhost:5173 (ต้องผ่าน server ไม่ใช่ดับเบิลคลิกไฟล์ ไม่งั้น localStorage ไม่ทำงาน)
dev server จำลอง `/api/roster` และ `/api/state` ไว้ในหน่วยความจำให้ด้วย — ทดสอบทั้งซิงก์รายชื่อและโหมดดูสดได้โดยไม่ต้องต่อ Upstash

## ไฟล์ในโฟลเดอร์

- `index.html` — ตัวแอปทั้งหมด (HTML + CSS + JS ไฟล์เดียว ไม่มี dependency)
- `api/roster.js` — API รายชื่อส่วนกลาง (Vercel serverless function, ไม่ใช้ npm package)
- `api/state.js` — API สถานะก๊วนสำหรับโหมดดูสด (สนาม/คิวปัจจุบัน + จำนวนคนออนไลน์)
- `vercel.json` — ตั้งค่า cache
- `index-old.html` — เวอร์ชันก่อนปรับ (2 สนามตายตัว + เมนูแชร์) ลบทิ้งได้
- `.claude/serve.js`, `.claude/launch.json` — dev server สำหรับทดสอบ ไม่เกี่ยวกับตัวแอปตอน deploy
